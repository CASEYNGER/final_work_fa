## Цели проекта

1. Подготовить исходные данные для дальнейшего аналитического исследования.
2. Провести ETL и исследовательский анализ данных (EDA).
3. Изучить динамику продаж, выручки и прибыльности.
4. Выполнить ABC/XYZ-анализ товарного ассортимента.
5. Провести RFM-сегментацию клиентской базы.
6. Сформулировать бизнес-выводы и рекомендации.
7. Разработать интерактивный BI-дашборд для представления результатов.

## Этапы работы

### 1. ETL и предварительная обработка

Ноутбук: `01_etl_and_preprocessing.ipynb`

На первом этапе выполнена подготовка исходных данных:

- проверка структуры и типов данных;
- анализ пропущенных значений;
- поиск и удаление полных дубликатов;
- проверка корректности дат и числовых показателей;
- выявление аномальных значений;
- обработка некорректных записей;
- создание производных аналитических признаков;
- формирование флагов качества данных и бизнес-правил;
- подготовка аналитических CSV-файлов.

Результатом этапа стал набор очищенных и подготовленных данных для дальнейшего анализа и BI-визуализации.

### 2. Исследовательский анализ данных (EDA)

Ноутбук: `02_eda_and_abc_xyz.ipynb`

На этапе EDA исследованы:

- динамика продаж за анализируемый период;
- месячная и годовая выручка;
- распределение продаж;
- показатели прибыльности;
- особенности продаж по товарным категориям и подкатегориям;
- характеристики заказов и каналов продаж;
- распределение клиентской базы.

Для анализа использованы описательная статистика, группировки, агрегации и визуализация данных.

### 3. ABC-анализ

ABC-анализ применён для определения вклада товарных позиций в общую выручку.

Товары и товарные группы распределены по трём категориям:

- **A** — позиции с наибольшим вкладом в выручку;
- **B** — позиции со средним вкладом;
- **C** — позиции с наименьшим вкладом.

Анализ проведён на нескольких уровнях товарной иерархии, включая SKU, подкатегории и категории.

### 4. XYZ-анализ

XYZ-анализ использован для оценки стабильности спроса на товары.

В основе расчёта — коэффициент вариации продаж:

\[
CV = \frac{\sigma}{\bar{x}}
\]

Группы:

- **X** — относительно стабильный спрос;
- **Y** — умеренная вариативность спроса;
- **Z** — высокая вариативность спроса.

Для анализа учитывались месяцы без продаж, что позволяет не игнорировать периоды отсутствия спроса.

Совместное использование ABC и XYZ позволяет оценивать одновременно финансовую значимость товаров и стабильность спроса на них.

### 5. RFM-сегментация

RFM-анализ применён для сегментации клиентов на основании трёх показателей:

- **Recency** — давность последней покупки;
- **Frequency** — частота покупок;
- **Monetary** — денежный вклад клиента.

На основании квинтильного скоринга сформированы клиентские сегменты:

- Champions;
- Loyal;
- Big Spenders;
- New;
- At Risk;
- Hibernating;
- Lost VIPs;
- Other.

Результаты позволяют определить наиболее ценные группы клиентов, а также потенциальную аудиторию для программ удержания и реактивации.

### Основные бизнес-наблюдения

**1. Динамика продаж**

В 2025 году наблюдается восстановление продаж после снижения в 2023–2024 годах. Выручка выросла примерно на 17% относительно 2022 года.

**2. Каналы продаж**

Канал Online формирует наибольшую долю выручки. B2B Portal демонстрирует высокий средний чек, что представляет интерес для дальнейшего изучения эффективности канала.

**3. Товарный ассортимент**

Все товары группы A по результатам проведённого анализа попали в группу Z. Это означает, что наиболее значимые с точки зрения выручки товары характеризуются высокой вариативностью спроса.

**4. Клиентская база**

Сегменты Champions и Loyal формируют значительную часть клиентской выручки. Их удержание представляет важное направление для развития клиентской стратегии.

**5. Клиенты с риском оттока**

Сегменты Hibernating и At Risk могут рассматриваться как потенциальная аудитория для реактивационных кампаний.

Для представления результатов исследования разработан интерактивный дашборд в Yandex DataLens.

**[Открыть дашборд](https://datalens.yandex/2dkc84cx7e3ul?_share_link=public)**

Дашборд включает пять аналитических разделов:

1. **Executive Summary** — основные показатели и общая картина бизнеса.
2. **Каналы и операции** — анализ продаж и операционных показателей.
3. **ABC/XYZ** — оценка товарного ассортимента по вкладу в выручку и стабильности спроса.
4. **Клиенты (RFM)** — сегментация клиентской базы.

## Ограничения и допущения

При интерпретации результатов необходимо учитывать следующие особенности:

- Для расчёта реализованных продаж используется аналитическое правило: статус заказа `Completed` и отсутствие признака возврата.
- RFM-анализ выполняется на основе клиентов, имеющих реализованные покупки.
- В XYZ-анализе учитываются месяцы без продаж в рамках выбранного периода наблюдения.
- Высокая вариативность спроса сама по себе не определяет оптимальный размер товарного запаса. Для этого дополнительно необходимы сведения об остатках, сроках поставки и дефиците.
- Денежные показатели интерпретируются в соответствии с определениями исходного датасета. Валютная база показателей требует отдельного подтверждения по источнику данных.
